Anfora Gold — boshqaruv

Telegram kanaldagi postlar saytga avtomatik tushadi. Bu yerda ularning nomi, holati, kategoriyasini o'zgartirish, keraksizini yashirish va kunlik narxni kiritish mumkin.

Saytga joylanmagan o'zgarishlar bor

O'zgarishlar hozircha faqat shu brauzerda turibdi. Mijozlar ko'rishi uchun "Saytga joylash" tugmasini bosing — 1–2 daqiqada saytda chiqadi.

Qanday ishlatiladi

  1. Quyida narx, holat va mahsulotlarni o'zgartiring.
  2. "Saytga joylash" tugmasini bosing. 1–2 daqiqadan keyin saytni yangilang (pastga tortib yoki F5).
  3. Birinchi marta joylashda GitHub kaliti (token) so'raladi — u faqat shu qurilmada saqlanadi. Kalitni qanday olish?
GitHub kalitini olish (bir marta):
  1. github.com/settings/personal-access-tokens/new sahifasini oching.
  2. Token name: anfora-admin, Expiration: 1 yil (yoki xohlaganingiz).
  3. Repository access: Only select repositories → anfora-gold-sayt.
  4. Permissions → Repository permissions → Contents: Read and write va Actions: Read and write.
  5. Generate token → chiqqan kalitni nusxalang va shu yerda "Saytga joylash" bosilganda chiqadigan oynaga qo'ying.

Kalitni hech kimga yubormang. Boshqa kompyuterda admin ochsangiz, kalitni o'sha yerda qayta kiritasiz.

Kunlik narx

Narx kiritilsa, saytda har bir buyumning taxminiy narxi (og'irlik × 1 gramm narxi) ko'rsatiladi. Bo'sh qoldirilsa, "So'rov bo'yicha" yoziladi.
